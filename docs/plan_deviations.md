# Plan assumptions checked against the code

The improvement plan was written from the README and results summary.
The code audit found these starting conditions:

- The sweep already uses seeded Latin hypercube sampling.
- The mode tracker already computes MAC on four motor-tip XYZ displacement
  vectors and compares one near-degenerate pair by subspace overlap. It does
  not yet track general clusters or all flexible modes.
- The surrogate API already rejects inputs outside its saved parameter
  ranges.
- The old dataset saves six raw flexible frequencies but only three tracked
  targets. The Campbell screen consequently checks only those targets.
- The baseline is mesh-refined, while sweep cases use the configured target
  mesh size.

These findings change the implementation approach: extend and validate
existing mechanisms instead of adding parallel sampling, MAC, or range-check
implementations. The numerical audit is generated by
`python3 -m tools.audit_baseline` and stored under `results/audit/`.
